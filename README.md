# RabbiCode | Intelligent Data Solutions

**Turn Your Business Data Into Better Decisions.**

RabbiCode is an emerging data analytics and business intelligence company focused on helping businesses transform raw data into meaningful insights that support better decision-making, business growth, and operational efficiency.

Our goal is to make data-driven decision-making accessible to businesses, particularly small and medium-sized enterprises (SMEs).

## About RabbiCode

RabbiCode provides data-focused solutions designed to help businesses understand their performance, identify opportunities, and make informed decisions.

Our core service areas include:

- **Sales Analytics:** Understand revenue performance, sales trends, product performance, and business growth.
- **Business Intelligence:** Transform business data into meaningful dashboards and actionable insights.
- **Customer Analytics:** Discover customer behaviour, purchasing patterns, and opportunities to improve customer retention.

## Project Overview

This repository contains the RabbiCode business website and a demonstration Sales Analytics Dashboard built with Flask.

The dashboard demonstrates how business data can be presented through interactive visualizations, key performance indicators, and business insights.

### Sales Analytics Dashboard

The current demonstration dashboard includes:

- Total Revenue
- Total Orders
- Units Sold
- Average Order Value
- Monthly Sales Trends
- Top-Selling Products
- Business Insights and Recommendations

The dashboard currently uses demonstration sales figures to illustrate how RabbiCode can communicate business performance.

## Running the Project Locally

Follow these steps to run RabbiCode on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/Ugwuonu-github2/RabbiCode.git
```

### 2. Navigate into the project directory

```bash
cd RabbiCode
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python -m flask --app app run
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```

To access the demonstration dashboard:

```text
http://127.0.0.1:5000/dashboard
```
